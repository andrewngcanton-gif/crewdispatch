# Contributing

CrewDispatch 0.1.x is currently an owner-directed project. The public repository is a curated source/release mirror of the canonical development repository.

External pull requests are **not accepted at this stage**. Please do not invest time in a large implementation expecting it to be merged.

Reproducible bug reports are welcome. A useful report includes the CrewDispatch version, operating system/architecture, provider involved, the command or action that failed, and a minimal redacted error. Never post credentials, provider tokens, private transcripts, or personal data.

The policy may be relaxed after the public interfaces and provider/runtime boundaries stabilize.
